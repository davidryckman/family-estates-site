# Family Estates website design

A calm editorial presentation of the app's established visual world: ivory paper, deep forest lettering, restrained gold rules, realistic autumn scenery, and the supplied ornate house crest. The content should feel like a welcome, not a real-estate listing or a generic software product.

## Tokens

- Paper #f7f3eb; surface #fffcf7; deep forest #173f35; ink #172e27.
- Muted forest #52635a; gold #906b2f; hairline #d8ccba.
- Display: self-hosted Cormorant Garamond, 400–600; body: native UI sans.
- Display size 2.5–6rem, tracking −0.025em, line height 1.02–1.14.
- Body 1rem, line height 1.7; reading measure 66ch.
- Main width 1180px; outer gutters 28px desktop, 22px mobile, 18px at widths of 380px or less.
- Portrait phone frame 8px matte forest edge, 42px corner radius (36px on mobile); editorial images 12px corners.
- Elevation emphasizes the device and photo objects: 0 28px 60px rgba(22,43,34,.18). The activity preview and mobile menu use smaller offset soft shadows.

## Composition and behavior

The landing page pairs a large welcome with the supplied sign-in artwork, then introduces the fictional Estate through one panoramic image and an editorial feature section. Long-form support/policy pages use a clear title, local navigation and a reading column. No live app controls or public registration are implied. Coming Soon is a disabled availability control, not a fake link. Navigation and its native details menu are keyboard-accessible; reduced-motion users receive no animation.
